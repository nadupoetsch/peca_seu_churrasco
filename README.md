# Peça seu Churrasco 🥩📱

Aplicativo desenvolvido como **projeto acadêmico em equipe**, utilizando React Native no aplicativo, Node.js/Express no back-end e MySQL para persistência de dados.

O projeto registra experiência prática com desenvolvimento de software, integração entre aplicação e banco de dados e colaboração em equipe.

## Tecnologias

- React Native
- JavaScript
- Node.js
- Express
- MySQL
- React Navigation

## Estrutura

- `src/` — código principal da aplicação
- `Authentication.js` — recursos relacionados à autenticação
- back-end Node/Express para comunicação com o banco de dados

## Como executar

É necessário possuir um ambiente React Native configurado, Node.js e as dependências utilizadas pelo projeto.

Principais dependências utilizadas:

- `@react-native-community/checkbox`
- `@react-native-picker/picker`
- `@react-navigation/bottom-tabs`
- `@react-navigation/native`
- `@react-navigation/native-stack`
- `body-parser`
- `cors`
- `express`
- `mysql`
- `react`
- `react-native`
- `react-native-picker-select`
- `react-native-safe-area-context`
- `react-native-screens`

Com o ambiente configurado, o fluxo utilizado no desenvolvimento era executado em terminais separados:

```bash
npm start
```

No diretório responsável pelo back-end:

```bash
node routes
```

E para iniciar a aplicação Android:

```bash
npm run android
```

> Este repositório representa um projeto acadêmico e pode exigir ajustes de ambiente/dependências para execução em versões atuais das ferramentas.
